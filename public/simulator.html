Merge request

Status legend

📝 Draft→ 👀 Open→ ✅ Approved→ 🔀 Merged  ·  any state → 🚫 Closed
📝 Draft
work in progress, not up for review
👀 Open
in flight, waiting for review
✅ Approved
quorum reached, cleared to merge
🔀 Merged
landed in the target branch
🚫 Closed
dropped without merging

One vocabulary: a reply that moves the MR into a state opens with that state's glyph, so 🔀 Merged into master in the thread and 🔀 in the parent read as one fact. Events that change no state keep glyphs of their own — 👍 approval, ↩️ revoked, ⚠️ quorum lost, 🧵 threads resolved.
